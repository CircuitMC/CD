# CD — CircuitMC Default Texture

A fully original, vanilla-style resource pack for the CircuitMC client and Minecraft: Java Edition.
Every texture is generated by the code in this repository — no Mojang artwork is copied, traced or
derived (see [docs/STYLE.md](docs/STYLE.md) for the clean-room rules).

- **Complete:** all 3,964 textures of Java 26.3, plus the old texture names/layouts of earlier versions
- **Almost every version:** 1.7.10 → 26.x (two downloads, see below)
- **Resolutions:** 16x (pixel art), 64x, 256x, 1024x — rendered from the same generators, so the design
  is identical and higher resolutions add real detail
- **Shaders:** LabPBR 1.3 normal (`_n`) and specular (`_s`) maps for blocks, items and entities
  (height/parallax, AO, smoothness, metals, porosity, subsurface scattering, emission)
- **Connected glass:** OptiFine CTM `ctm_compact` for glass, tinted and all stained glass and panes
  (also works with the Continuity mod)
- **Add-on — CircuitMC Redstone Power:** shows the signal strength 0–15 on redstone dust; plain vanilla,
  no mods needed
- **License:** [CC BY-NC-SA 4.0](LICENSE); commercial licenses available separately
  ([COMMERCIAL.md](COMMERCIAL.md))

## Downloads

| File | For |
|---|---|
| `CircuitMC-Default-<ver>-<res>x.zip` | Java 1.13 → 26.x (one pack; uses pack overlays on 1.20.2+) |
| `CircuitMC-Default-Legacy-<ver>-<res>x.zip` | Java 1.7.10 → 1.12.2 |
| `CircuitMC-Redstone-Power-<ver>-<res>x.zip` | optional add-on, 1.13+; put it above the main pack |

Clients older than 1.20 (and 1.7–1.10 for the legacy pack) label the pack "made for a newer/older
version" — it still works; confirm the prompt.

Tested by loading the 16x packs in real clients (title screen + resource reload, no texture errors):
26.3, 1.21.1, 1.20.1, 1.16.5 (main pack + redstone add-on), 1.12.2 and 1.8.9 (legacy pack).

**Which resolution?** 16x looks like the classic game and runs everywhere. 64x and 256x need more video
memory. 1024x means every block texture is 1024×1024: the block atlas alone needs well over 4 GB of video
memory and may exceed the maximum texture size of many GPUs — use it only on high-end hardware. The
1024x pack (about 20 GB) is too large for GitHub release downloads; build it locally with
`build.py --res 1024`.

## Known limitations

- The legacy Unicode glyph pages (`font/unicode_page_*`, used by 1.13–1.19 for scripts outside
  Latin/Greek/Cyrillic) are not included; the game's own glyphs are used for those characters.
- On 1.13–1.16 accented/non-Latin characters from `accented.png`/`nonlatin_european.png` can show the
  wrong glyph: those versions used different sheet sizes that one pack folder cannot serve together with
  1.17–1.20.1. ASCII text is correct everywhere.
- On 1.20–1.20.1 the title-screen logo looks scrambled: those two versions use a different logo sheet
  than 1.13–1.19 at the same path, and the shared base folder serves the 1.13–1.19 layout.
- A few model UV layouts were inferred rather than verified in game (some 26.x blocks such as beds,
  candles and shelves; a handful of entities). Reports are welcome.

## Build

```bash
python3 -m venv .venv && .venv/bin/pip install numpy pillow
.venv/bin/python build.py --res 16 64 256 1024     # all packs, all resolutions
.venv/bin/python build.py --res 16 --area block_stone --no-zip --preview   # one work area
.venv/bin/python tools/validate.py                 # structural checks of dist/
.venv/bin/python tools/mc_test.py 1.21.1 dist/CircuitMC-Default-*-16x.zip  # load in a real client
```

Builds are deterministic. Hand-drawn PNGs in `overrides/<res>x/assets/...` (or `overrides/16x/`,
auto-upscaled) replace generated ones.

## Layout

```
generator/engine.py      resolution-independent engine (noise, shapes, PBR layers, LabPBR encoding)
generator/materials.py   reusable material builders (rock, soil, masonry, planks, ore, leaves, ...)
generator/sprites.py     shaded, outlined sprites for items, plants, icons
generator/textures/      generators per work area: block/, item/, entity/, gui/, misc/, legacy/, addons/
data/vanilla-*.json      vanilla interface data per version: paths, image sizes, .mcmeta (no pixel data)
data/aliases.json        old texture names -> modern generators;  data/old_only.json: old-only textures
data/assignments.json    work area that owns each 26.3 path
tools/                   indexer, work-area tools, validator, in-game smoke test
```
