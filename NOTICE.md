## Originality

Every texture in this pack is an independent creation, produced by the generator code in this repository
or hand-drawn by contributors. None is copied, traced, sampled or derived from Mojang Studios / Microsoft
artwork. Only functional interface data of the vanilla game was used for compatibility: file paths, image
dimensions, `.mcmeta` metadata and font character tables, read from the client jar's file table via HTTP
range requests — no vanilla image data was ever downloaded or viewed. Entity UV box positions (where each
model face sits on a texture sheet) were taken as plain numbers from the community-maintained text model
templates at https://github.com/ewanhowell5195/cemTemplateModels; no images from that or any other source
were used. The Git history documents how each texture was made.
